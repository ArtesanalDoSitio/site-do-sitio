## Princípios visuais
- Fotografia em destaque (produto e processo artesanal)
- Espaçamento generoso, poucas colunas
- Poucos elementos de UI visíveis — foco no conteúdo
- Linguagem visual editorial, baixo contraste de "app"

## Responsividade
- Mobile e desktop com prioridade igual
- Grid fluido, imagens responsivas, breakpoints padrão (mobile / tablet / desktop)

## Estados de tela
- Tratamento padrão (sem customização especial por tela) para: carregando, vazio/sem resultados, erro, sem conexão, login inválido
- Padrões consistentes de spinner/skeleton, mensagens neutras e CTA de retorno (ex.: "voltar ao catálogo")
